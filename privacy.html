NV Robot privacy policy

NV Robot uses Google sign-in only for the owner's own YouTube account, to create playlists and add videos to them. It requests the YouTube scope and nothing else.

  • It does not read, store or share any other Google account data.
  • The access token is kept only on the owner's private server and is never shared with anyone.
  • No data is sold, used for advertising, or sent to third parties.
  • Access can be revoked at any time at myaccount.google.com/permissions.

NV Robot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Questions: open an issue at github.com/vanderslicenicholas-max/nv-robot-site.
